
# Chat With Your Documents

## Project Description
A basic Retrieval-Augmented Generation (RAG) application that allows users to ask questions about PDF documents.

## Features
- PDF text extraction
- Text chunking
- TF-IDF embeddings
- Similarity search
- Relevant information retrieval
- Streamlit web interface

## Technologies Used
- Python
- Streamlit
- PyPDF
- Scikit-learn

## How to Run

1. Install dependencies:

   pip install -r requirements.txt

2. Run the application:

   streamlit run streamlit_app.py
